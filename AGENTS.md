# Contribution workflow

This repository protects `main`. Direct commits and direct pushes to `main` are not permitted.

For every code change:

1. Fork the repository and create a focused feature branch in the fork.
2. Make, test, and commit the change on that feature branch.
3. Open a pull request from the fork to `main` in this repository.
4. Merge through the pull request; never bypass the PR flow by pushing to `main`.

Pull requests are mandatory, but an approval is not required to merge. Agents must follow this workflow as well.
